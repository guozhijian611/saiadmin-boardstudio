# Board Studio V2 开发与验收

起点：`c1a77a5`（1.1.3）。目标为独立 SaiAdmin 6 插件，不改原 saiboard。

## 已确定的模型边界

- 文档 schemaVersion=2，以根容器、节点表、子节点顺序表达树。最大 200 节点、12 层、2 MiB。
- 容器支持 free/flex/grid；父容器排版与子节点占位独立。切换布局保留原坐标，作为一次可撤销命令。
- 文档不保存选择、缩放、加载错误或请求句柄。组件配置与数据绑定实例分别管理。
- 设计与播放器使用同一容器/节点样式解释器；浏览器 CSS 负责 Flex/Grid 排版。
- 复制重建整个子树 ID；循环、游离节点和多父节点拒绝保存。锁定向子树生效。
- 旧布局通过显式导入复制转换，不在安装时覆盖旧数据。

## 实现阶段及完成判据

1. 文档、布局与编辑器：嵌套三模式，属性修改、树操作、拖放、复制、撤销、保存刷新、预览一致性。
2. 数据集：连接与凭据分离；可视化关联查询、只读参数 SQL、HTTP 查询；参数和字段契约；执行/使用/编辑授权。
3. 数据运行：按绑定实例合并请求；参数、数据集版本、授权范围参与缓存；隐藏暂停、失败退避、过期提示。
4. 发布：不可变文档与数据集版本；发布检查；公开/登录/令牌策略；撤权即时生效；回退不覆盖草稿。
5. 完整交付：组件注册和原组件迁入、内置预设、旧屏转换；独立 MySQL/PostgreSQL 实验室 ZIP 安装升级及浏览器闭环。

## 数据设计约束

数据源是连接；数据集是带版本的查询定义；绑定实例是当前页面的参数和刷新覆盖；组件只声明字段映射。
SQL 不依赖字符串拼接授权：使用受限只读账号/视图和服务端权限。租户授权不能靠普通参数冒充。
HTTP 由后端访问管理员批准的目标；有界响应、分页、重定向与超时。运行配置不得泄露密钥。
轮询默认 30 秒、最小 10 秒、每屏并发 4；慢请求结束后再计时。缓存与请求频率分别显示。
发布固定查询定义，连接密钥和访问撤销保持实时；不承诺外部数据库结构永不变化。

### 参数联动与编辑交互阶段

页面参数保存类型和默认值，绑定常量与引用显式区分：`{"customer":{"pageParameter":"customer"}}`。
参数定义属于文档历史；播放时参数值仅存在于会话，不改变发布文档。编辑和播放采用相同解析规则。
服务端按发布快照校验声明、类型及引用；客户端不能通过额外字段更换数据集、绑定或查询定义。
参数切换会清空旧身份结果；相同身份轮询失败仍保留最近成功数据。隐藏容器连同子树停止取数。

## V2 再评估与交付门槛

当前属于可演示开发版，不能用参数联动成功替代授权、升级和双库验收。

1. **P0 数据边界**：数据源配置目前仍走旧配置对象；须完成凭据加密存储、读取脱敏、空白保留/显式替换语义及错误脱敏。查询使用权不应等于连接管理权，也不应让仅能看大屏的人获得 SQL 或请求头。数据集列表的 use/edit/manage 可见性与连接授权需要统一。
2. **P0 行级范围**：页面参数只表达业务筛选，不代表授权范围。公开屏只能绑定可公开的数据；登录屏若需租户/部门隔离，执行器必须从登录身份注入不可由客户端覆盖的授权约束，并把范围纳入缓存键。当前发布数据以屏幕所有者执行；它适合统一展示的授权结果，不等于按每个观看者自动隔离。此限制必须在发布检查和文档中明确。
3. **P1 数据集契约**：字段名/类型、默认参数及查询版本共同形成契约。可视化关联需展示一对多造成的重复汇总风险；SQL 使用只读账号、受限语法、行数/体积/时间边界。HTTP 的超时需实际接入数据集 timeoutMs，分页若支持必须限定最大页数与总体积，避免无界抓取。
4. **P1 编辑器边界**：容器负责空间，组件负责呈现，绑定负责取数。选择/缩放/预览值不入文档，编辑动作都走命令历史。当前为单选和结构树拖放；框选、多选对齐及画布直接落位应作为完整独立交互完成，不能与现有单选状态混搭。参数面板还需友好标签、候选值与字段选择，避免普通用户填写 JSON。
5. **P1 发布和运行**：草稿保存、发布快照、访问策略分离。切换发布版本不覆盖草稿；轮询失败保留同查询最后成功结果，但换参数必须清空旧结果。还需验证登录授权撤销、缓存并发合并、长时间运行、断网恢复及屏幕多实例负载。页面重新取数、组件动画/轮播、浏览器整页重载是三个不同设置，不共用一个“刷新时间”。
6. **P1 安装契约**：V2 预设导入、旧屏显式迁移、导入导出版本校验、MySQL/PostgreSQL 存储迁移和最终 ZIP 首装/升级/重复上传/保数据卸载必须以同一最终包验证。PostgreSQL 存储支持不等于已具备 PostgreSQL 业务数据源连接器。

推荐剩余顺序：先凭据/权限与身份范围，再完善数据集 UI 和限制，然后 V2 组件/预设与导入导出，最后浏览器完整业务链、故障测试、双库最终包验收。V2 首版范围为嵌套 free/flex/grid、核心组件、MySQL 与 HTTP 数据集、参数联动及三种发布策略；不把跨数据库关联、任意脚本执行、全 SQL 方言和在线模板市场混入首版。

### 凭据与资源权限加固

第七次迁移把历史连接配置转换为 AES-256-GCM 密文，密钥与数据库分离。模型序列化统一脱敏密码、全部 HTTP 请求头和默认参数；明文只在后端执行期间使用。更新支持留空保留与显式清空，未保存表单测试复用相同合并规则。基础 URL 不再接受内嵌认证或查询字段。插件审计仅记录元数据，避免自定义请求头绕过宿主按字段名脱敏规则。
默认密钥文件与环境变量配置、备份和恢复见插件 README。没有原始密钥的实例必须恢复密钥，不能生成新密钥冒充恢复；运行检查器不输出秘密。回滚时存在数据源则拒绝将其还原为明文。

资源授权 UI 已覆盖连接、数据集与登录大屏。数据集列表按 use/edit/manage 权限裁剪：use-only 账号拿不到查询定义，仍可执行；连接只有管理者可查看脱敏配置和编辑。登录大屏 view 仅允许播放，不授予草稿或连接权限。

MySQL 临时环境证据：历史连接迁移后直接查询成功；HTTP 读取脱敏、留空更新、保存态及表单态连接测试通过。真实非管理员 JWT + 菜单权限 + 资源授权验证通过：使用数据集、拒绝连接读取、拒绝草稿、数据集撤权、登录大屏授权及撤销即生效。浏览器确认脱敏编辑表单连接成功，连接授权 UI 正常。修复审计用户名长度边界和官方宿主未注册 SaButton 导致编辑按钮不可见的问题。
HTTP 的 timeoutMs 已接入请求，900ms 延迟端点在 100ms 超时下中止；GET/POST、私网精确允许、超大响应和重定向拒绝回归继续通过。

`tools/boardstudio/tests/authorization_http.py --help` 描述可移植的双账号权限验收脚本。该脚本只应用于指定一次性测试屏和用户，且需显式 `--disposable-fixture`，会发布登录版本并增删指定测试账号的资源授权。
当前仍需完成：观看者行级范围、数据集字段契约、V2 预设/导入导出、多选与对齐、查询并发合并、最终双库 ZIP 验收。密钥轮换尚无在线操作入口。
额外验证：自定义名称的请求头和默认参数均被遮蔽，使用脱敏值保存后原值保持不变；最近操作日志不含测试密钥字符串。权限脚本在失败时也会清理本次添加的直接授权，且拒绝复用已有直接授权的测试身份。

### 观看者范围与 V2 预设整合

数据集新增 `scope.mode=shared|viewer`。viewer 可选择当前用户或当前部门，以及查询表别名下的范围字段；身份每次从宿主账号表读取，缺失/停用用户和无部门账号拒绝执行。授权用户仍需具备大屏观看权限。
可视化 SQL 及手写 SQL 均在聚合之前附加服务端等值条件；原 WHERE 包括 OR 时整体加括号，范围条件无法被业务参数覆盖。缓存键包含解析后的身份范围。viewer 数据集仅允许登录模式发布，公开/令牌模式及不匹配的历史版本切换会拒绝。HTTP 上游范围暂不支持，租户映射不猜测为部门。

独立 MySQL 验证：同一查询与发布屏，用户 1 为 30、用户 987650 为 70，交替请求不串缓存；客户端伪造身份参数拒绝；公开和令牌发布拒绝。部门测试同部门账号为 190、另一部门为 30，停用和缺失身份拒绝。
`tools/boardstudio/tests/viewer_scope_http.py --help` 提供已准备登录屏的只读双账号验收，账号、预期值及地址全部通过参数提供。

V2 设计器内接入预设图库、组件组容器插入、整屏套用以及 JSON 文档导入/导出。组件组统一生成新 ID，操作一次撤销；整屏替换支持撤销，文档导入先校验再确认，导出提供完整 JSON 检视及下载。

### 多选与原子批量编辑

V2 设计区与结构树支持 Shift 增减选择；在容器空白处拖动，按完整包围规则框选该容器的直接子节点。多选工具栏固定占位，避免选择变化时画布跳动。右侧切换为批量面板，避免多选时误以为单个组件的属性会应用到全部节点。

- 同一个自由布局容器内支持整组拖动、六种边缘/中心对齐；至少三个节点支持水平/垂直等距。Flex/Grid 的位置由容器负责，多选对齐明确拒绝跨容器或非自由布局。
- 复制、删除、隐藏、显示、锁定、解锁均通过原子批量命令，一次撤销恢复整组。父子同时选中时只处理最高层选择，避免重复删除或复制。
- 锁定节点/祖先使整组修改失败，不会只修改部分节点。拖动预览在命令校验失败前恢复原位置。预览及输入框、对话框内不触发编辑删除快捷键。
- 组件预设使用插入子树命令，保留一条撤销历史；与插入目标无关的锁定节点不再错误阻止插入。子树重复、循环、游离节点及 ID 冲突均拒绝。

Chrome 已验证：框选两个自由布局组件；整组从 (16,16)/(16,100) 移到 (56,36)/(56,120)；顶对齐后一次撤销恢复；两节点复制使节点总数 11→13，撤销恢复；批量删除 11→9，撤销恢复；批量锁定后对齐被拒绝，撤销锁定后恢复操作。测试未保存覆盖演示草稿。核心回归共 21 项，官方隔离前端 vue-tsc 通过。

### 数据集输出契约与参数绑定

`definition.fields` 是可选的版本化字段列表，每项包含 `name`、`label`、`type`（string/number/boolean/object）、`nullable`。非空声明时，执行器只返回声明字段，检查缺失字段、空值和类型；空结果仍返回字段元数据。DECIMAL 数字字符串保留原精度，0/1 布尔值规范化，其他错误类型拒绝。旧数据集未声明字段时继续自动推断。发布检查会按固定的数据集版本检查组件映射字段及数字类型；它不主动执行所有查询，因此数据在运行时变形仍由执行器报错。

数据集编辑器支持手工维护字段或采用当前预览字段，再保存为新版本。绑定面板提供分类/数字字段候选，参数可选默认值、固定值或同类型页面参数；高级 JSON 仍可查看和编辑。修改已有绑定会保留其固定版本号。无权编辑的数据集不显示编辑按钮。

### 查询并发与故障恢复

V2 开启缓存时，使用 Redis 原子锁合并同身份、同范围、同数据集版本及参数的缓存未命中查询。Redis 不可用或明确关闭时退回同机非阻塞文件锁；锁等待受数据集时限约束，不会无限阻塞。多主机部署需共享 Redis，文件锁只保证共享该文件系统的进程间合并。缓存关闭（0 秒）明确保持每次重新执行。查询异常不会缓存，锁在 finally 释放。授权、资源状态和行级范围在读取缓存前检查。

隔离服务根目录内可复制运行以下两个无固定临时路径的脚本：

```sh
# 将 tools/boardstudio/tests/cache_probe.php 与 cache_matrix.php 复制到隔离 server 根目录
php cache_matrix.php
BOARDSTUDIO_REDIS_LOCK=false php cache_matrix.php
```

两种模式均实测 8 个独立 PHP 进程：仅一个执行者，7 个消费者复用相同结果；失败后下一次重新执行；缓存关闭连续两次均重新执行。此测试覆盖跨进程合并与恢复，不代表任意规模压力测试。

前端暂时故障保留同一查询最近成功结果并标记过期；参数变化清空旧值。401/403/404/409 视为授权/资源/版本失效，清空该绑定结果并暂停自动重试，用户手动重试或重新载入。播放器增加重新加载发布版本入口；登录播放器每次请求重新检查账号是否仍有效。

Chrome 实测临时移开测试表导致查询失败，界面保留 30 并标记“上次成功结果（已过期）”；恢复测试表后手动刷新回到“已更新”，结果 30，数据时间更新。测试表已恢复。非管理员 HTTP 权限回归通过：use-only 不暴露 SQL，撤销数据集及大屏权限后立即拒绝。24 项核心回归及隔离前端整体类型检查通过。
